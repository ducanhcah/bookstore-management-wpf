# Quản lý nhà sách

Ứng dụng desktop quản lý sách và lập hóa đơn cho nhà sách.

## Chức năng

- Đăng nhập và quản lý sách, thể loại.
- Tìm kiếm và lọc sách.
- Lập hóa đơn, tính tổng tiền và cập nhật tồn kho.

## Công nghệ

- C# và WPF
- Entity Framework 6
- SQL Server
- .NET Framework 4.7.2

## Cách mở

Mở `NguyenDucAnh_3324\NguyenDucAnh_3324.slnx` bằng Visual Studio, khôi phục các gói NuGet nếu được yêu cầu, rồi chạy dự án. Nếu dùng cơ sở dữ liệu SQL Server khác, hãy cập nhật connection string trong `App.config`.
